# Демонстрация сайта натяжных потолков

Сайт: https://yolokdd1-alt.github.io/ceiling-demo/

Статическая демонстрация: страницы, калькулятор и визуализатор. Без базы данных, отправки заявок, паролей и панели компании. Цены и материалы пока демонстрационные.

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. Файл `.nojekyll` сохраняет доступность ресурсов Next.js.

Для обновления: установить зависимости (`pnpm install`), выполнить `SITE_URL=https://yolokdd1-alt.github.io/ceiling-demo/ pnpm build`, заменить содержимое `docs` файлами из `out`, добавить пустой `docs/.nojekyll`, закоммитить и отправить изменения. Node.js 24, pnpm 11.
